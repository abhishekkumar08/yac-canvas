# Interop

- `excalidraw.js` — import/export `.excalidraw` v2: rectangle, ellipse, diamond, text (+ bound text), arrow/line (heads, bindings, elbow/curved), freedraw, image (+ files), frame/magicframe, embeddable/iframe → rect with link text. Export maps shape/sticky/table → rectangle; path and instance are skipped. Pressures, crop, custom fonts and binding focus/gap are not kept.
- `drawio.js` — async import of `.drawio` (plain or deflate-compressed pages): rect/rounded, ellipse, rhombus, text, image (data URIs), cylinder/process/document/parallelogram/hexagon/triangle/cloud/step/note/card/callout + any matching canvas shape kind, swimlane/container → frame, group → groupIds, edges (bindings, exit/entry, orthogonal/curved, waypoints, arrow ends, labels). HTML labels flattened to text. Not supported: layers as pages, stencils, tables, custom fonts, rich text. Export writes uncompressed XML, one diagram per page; path/instance skipped, other shape kinds written as `shape=<kind>`.
- `mermaid.js` — `graph`/`flowchart` (all directions, node shapes, link styles, labels, `&`, chains, subgraphs → frames, `classDef`/`class`/`style`/`:::`) laid out with `treeLayout`; minimal `sequenceDiagram` (participants, lifelines, messages; notes/loops/activations ignored). Other diagram types throw.
- `svg.js` — `svgToImage` validates `<svg>`, strips script/foreignObject, `on*` handlers, non-`data:`/`#` hrefs and external `url()`, returns a base64 data URL with size from width/height/viewBox.
